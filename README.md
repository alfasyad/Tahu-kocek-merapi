# Tahu Kocek Merapi - Aplikasi Android

1. Buat akun gratis di github.com, lalu buat repository baru (misal: tahu-kocek).
2. Upload SEMUA isi folder ini (termasuk folder .github dan www) ke repository tersebut.
3. Buka tab Actions, tunggu "Build APK" selesai (sekitar 5-10 menit, ada tanda centang hijau).
4. Klik run yang selesai, lalu di bagian Artifacts download "tahu-kocek-merapi-apk".
5. Ekstrak zip-nya, kirim file app-debug.apk ke HP, buka, dan izinkan "Install dari sumber tidak dikenal".

Nomor WhatsApp diubah di www/index.html pada baris: var WA="6281234567890";
